# Glossary

**Learner** — the person practising a language with Sieacher. For now there is exactly one Learner (the author).

**Tutor** — the AI persona the Learner converses with, named Lulu. It speaks the Target language, adapts to the Learner's Level, and gives Corrections.

**App language** — the language of the interface and of all explanations. The Learner's own language, picked on the first screen: Polish, English or German.

**Target language** — a language the Learner is learning. Currently English or German.

**Level** — the Learner's self-chosen proficiency in one Target language, on the CEFR scale (A1–C2). Each Target language has its own Level; the Learner can change it at any time.

**Conversation** — one continuous exchange of Messages between the Learner and the Tutor, in a single Target language at a single Level. The Level never changes during a Conversation; choosing a different Level starts a new Conversation.

**Topic** — what a Conversation is about. The Learner either types their own or picks one of a few suggested Topics.

**Message** — one turn in a Conversation, written by either the Learner or the Tutor.

**Opening** — the Tutor's first Message in a Conversation, about the Topic, written before the Learner says anything.

**Correction** — the Tutor's fix of a mistake in a Learner's Message: the corrected form plus a short explanation in the App language. Corrections are shown alongside the Tutor's reply and never interrupt the Conversation. Every Correction is an occurrence of one Mistake.

**Mistake** — a recurring pattern of error in the Learner's language (e.g. "present tense instead of past simple"), as opposed to a single wrong sentence. One Mistake has many Corrections across Conversations.

**Mistake category** — the kind of a Mistake (e.g. "case", "tense"), from a fixed list per Target language. Every Correction has exactly one.

**Check** — a moment where the Tutor deliberately gives the Learner a chance to use the form a Mistake is about. A Check is either passed or failed.

**Learned** — the state of a Mistake after enough passed Checks. A Learned Mistake stops being checked, and becomes un-learned if the Learner makes it again.
