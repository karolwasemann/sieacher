# Sieacher — language tutor app

Sieacher is an AI tutor that helps users improve their language skills through conversation practice.

## Goal

Help users get better at speaking and writing a foreign language through regular conversation with an AI tutor.

## Languages

- **App language**: Polish (for now). The interface and any explanations in the user's native language are in Polish.
- **Languages to learn**: English and German.

## Language level

- The user chooses their level for each language they learn (for example A1–C2).
- The tutor adjusts its vocabulary, grammar and pace to the chosen level.
- The user can change the level at any time.

## How practice works

1. **Chat first**: the user practises by writing to the tutor in a text chat.
2. **Voice later**: the user practises by speaking. The app records their voice and the tutor replies.
